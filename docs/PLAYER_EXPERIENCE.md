# UI・操作・情報表示・アクセシビリティ・保存仕様 v1.0

> 完成したゲームのユーザー体験の正本。UIは入力と表示、ゲームルールの判断はProcess、取得/保存はData。責務境界は [upd-design](https://github.com/tomiya7688/upd-design) と [CODING_RULES](CODING_RULES.md) を厳守する。

## 1. メインの画面構成

### 起動画面

- **新しい都市**：マップ、seed、都市名、難易度、左/右側通行、災害頻度、マイルストーン解放の有無を選択。
- **続きから**：セーブの都市名、日時、人口、マップ、プレイ時間、保存バージョン、使用コンテンツパックを表示。
- **シナリオ**：目標、初期条件、制限時間/失敗条件、難度、想定プレイ時間を確認。
- **設定**：画質・描画距離/密度・言語・音量・操作・字幕/アクセシビリティ・自動保存。
- **終了**：作業中の都市は保存確認を表示。オンライン認証不要。

### プレイHUD

- **上部**：都市名、資金、直近の収支、人口/人口増減、住民満足度、ゲーム内日時、停止/速度、通知。
- **左下または左側**：道路、ゾーニング、電力、上水/下水、ごみ、交通、公共サービス、地形、地区政策、撤去。
- **右側**：選択中の建物/道路/住民/駅/バス路線の詳細パネル。画面上の位置に依存しないレイアウト切替可。
- **下部**：需要指標、建設予算、交通・電力・水道等の問題インジケータ、現在のツールのショートカット。
- **地図中央**：カメラによる都市の見た目、建設時プレビュー、必要な範囲の情報レイヤー。

**情報量の制御:** デフォルトでは重要な数値と警告だけを表示。指標をクリックすると推移グラフ・地区別内訳・原因・対象施設へドリルダウン。全レイヤーを重ねて見づらくしない。

## 2. 操作契約

初期キーバインド案（すべて再割り当て可能）:

| 操作 | デフォルト |
| --- | --- |
| カメラ平行移動 | WASD / 矢印キー / 画面端スクロール（OFF可） |
| カメラ回転 | Q / E、マウス中ボタンドラッグ |
| ズーム | マウスホイール / + / - |
| 選択 | 左クリック |
| 直前ツールのキャンセル・パネルを閉じる | Escape |
| 時間停止/再開 | Space |
| 時間速度 | 1=1x、2=2x、3=4x、4=8x |
| 情報レイヤー | L |
| 建設プラン内の取り消し | Ctrl+Z（確定済み都市状態の時間巻戻しではない） |
| 画像保存/写真モード | 設定可能なショートカット |

道路・線路は始点→必要な中間点→終点と描く。ゾーンはブラシ/矩形塗り。建物は影のプレビューで設置可否とコストを示し、確定で建設を依頼する。

### プレビューと確定

- 建設プレビュー中は**まだゲーム世界を変更しない**。接道、傾斜、線路/電線の接続、費用、既存建物への干渉を表示。
- 確定すると `CityCommand` がProcessへ渡され、`Accepted / Rejected(reason)` を返す。UIが資金・可否・信号の最終判断をしない。
- 確定前の連続配置計画なら取り消し/やり直しができる。確定後は撤去・再開発として別のコストと影響を持つ。**確定済みの都市をCtrl+Zで勝手に巻き戻さない**。
- 連続敷設時には費用累積と予算残を先読みし、途中で足りなくなる箇所を表示。
- カメラ移動・ツール切替では市民や車の論理移動を再計算しない。

## 3. 情報レイヤー

| レイヤー | 主な表示 | プレイヤーが判断できること |
| --- | --- | --- |
| ゾーニング | 4用途、密度、区画未利用 | 建物の立地・追加する用途 |
| 用途需要 | 住宅/商業/工業/オフィスの地区別不足 | どこにどの区画を増やすか |
| 人口・就業 | 人口密度・年齢構成・失業・勤務地 | 住宅/仕事/学校の不足 |
| 地価・満足度 | 土地価値、所得負担、満足度 | 施策の効果と副作用 |
| 交通渋滞 | 区間混雑・待機列・平均所要時間 | 道路/信号/交通手段の改善 |
| 徒歩アクセス | 歩道接続・横断・駅までの時間 | 徒歩移動の障害 |
| 公共交通 | 路線/停留所、利用者、混雑、定時性 | 路線・車両・運賃の調整 |
| 電力 | 系統、発電/需要、停電区域 | 発電所・送電線の配置 |
| 上下水道 | 配水/下水管、供給率、処理能力 | 管路接続、設備増設 |
| ごみ | 蓄積、収集範囲、処理施設 | 収集車・施設の追加 |
| 医療/教育 | 施設、サービス所要時間、空き定員 | 施設不足、道路アクセス |
| 警察/消防 | 担当区域、犯罪・火災リスク、到着時間 | 署の配置、路線改善 |
| 汚染/災害 | 大気・騒音・土壌/水質、被害区域 | 産業の位置、環境対策 |
| 財政/政策 | 税収/支出、地区政策、建設費 | 税率・予算・借入・運営 |

レイヤーはProcessの**読み取り用指標**を受け取る。ヒートマップの色や補間で論理値が変わることはない。色覚多様性に配慮したパレットと数値/模様による冗長表現を用意する。

## 4. 施設・道路・住民を選択したとき

### 建物

用途・レベル・入居/稼働率・現在の不足・必要なインフラ・税収/維持費・物流待機・騒音/公害・次の成長条件を表示。満員の施設は定員と待機人数を明示。

### 道路/交差点

平均速度・流入台数・待ち列・車/歩行者信号の位相・右左折制限・競合待ち・迂回先を表示。「渋滞しています」だけでなく**どの境界/容量が原因か**を分かるようにする。

### 住民

IDで追跡できる住民の表示名・世帯・自宅・勤務地/学校・現在のState・目的地・交通手段・到着予定を表示。顔の細部や会話などの完全な個別AIは不要。画面外のIDも必要時に現在位置を再構成し、見えない間の状態遷移を取りこぼさない。

### 路線/駅

運行系統、運行間隔、待機人数、乗客数、停留所別乗降、料金収支、遅延原因、容量不足を表示。

## 5. 警告と問題解決UI

警告は `AlertId / CauseId / Severity / Location / FirstSeenAt / LastSeenAt / ResolvedAt` を持つ。例：電力不足、下水未接続、渋滞、物流停滞、住戸不足、病床不足、犯罪増、赤字、洪水。

- 同じ原因で数千建物が影響されても、原則ひとつの問題グループとして表示し「影響建物数」を示す。
- 警告を選ぶと、地図で影響範囲・根本原因・改善候補（道路増強、設備増設、予算変更など）を確認できる。
- 原因が解決すると自動的に解決済みへ。既読化はUIからProcessへ送るコマンドであり、原因自体を消さない。
- 発生/解決の通知に音が必要なら、重要度と頻度に応じてまとめて鳴らし、警告音の連打を避ける。

## 6. チュートリアル・シナリオガイド

最初の起動では任意のチュートリアルを案内し、**操作を強制するモーダル連発を避ける**。ステップは都市の実データとリンクする。

1. カメラ移動・時間停止/再開。
2. 外部幹線へ道路を接続。
3. 住宅・商業・工業の用途区画を作る。
4. 電力・上水・下水を接続。
5. 建物が完成して世帯が入居するのを確認。
6. 仕事・税収・住民満足度を見る。
7. 渋滞地点にバス路線/交差点改良を施す。
8. セーブして再開する。

各チュートリアルは中断・再開可能で、説明を後からヘルプで参照できる。機能アンロック時には用途と費用/リスクを簡潔に表示。

## 7. 言語・アクセシビリティ・音

- **最初の公式UI言語は日本語と英語**。メッセージはUIへハードコードせずローカライズキーで管理。数値・通貨・小数・日時は言語に応じて表示形式を変える。
- 文字サイズ100/125/150%、高コントラストUI、色覚多様性プリセット、キー再割当、カメラ酔い軽減（カメラ揺れ/モーションブラーOFF）を提供。
- 重要な警告は音だけでなく文字とアイコンでも通知。操作のホバー説明とキーボードでのパネル移動を基本対象にする。
- BGM・環境音（車、列車、工業、商業、自然）・建設効果音・通知音を別スライダーで調整。大量の車両を個別音源として全件再生せず、距離/地区単位で音をミックスする。
- スクリーンショット/写真モードはUIを隠し、論理シミュレーションの時間停止設定を維持して撮影できる。

## 8. セーブ/ロードと障害回復

### セーブ機能

- 手動スロット複数、自動保存、任意で終了時保存。**標準の自動保存間隔は実時間10分**、保持する自動保存世代は5つ。設定可能。
- セーブはProcessが同時刻の確定イベント境界で不変スナップショットを構築。Dataはファイル形式への変換・圧縮・書込・エラー検知のみを担当する。
- 内容：世界seed、マップと地形/道路/建物、人口/世帯IDとState、集団索引の再構築に必要な値、運行予定、予約イベント、待機購読、容量予約、会計元帳、日時、乱数状態、バランス/コンテンツ版。
- フォーマットは**バージョン付きチャンク形式＋圧縮＋整合チェック（CRC等）**を初期方針とする。JVMオブジェクトのメモリグラフをそのままJava標準シリアライズする形式は採用しない。
- ファイルの書込は一時ファイルへ書いて検証後に原子的な置換を行い、旧世代をバックアップ。ディスク不足/壊れたデータで既存セーブを破損させない。
- 異なるバージョンは明示的なマイグレーションで変換し、非互換/欠損するコンテンツパックは安全にエラーまたは警告を返す。未対応で無理にロードして都市を壊さない。

### ロード・再現性

ロード要求はUI→Process→Data→Process→UIの責務順に処理。読み込んだ状態をProcessがID/容量/予約の不変条件で検証し、成功後だけ現行世界と入れ替える。

同じセーブ＋同じ入力＋同じseed/ルール版からは、画面描画の有無に関係なく論理結果を再現できることを目標にする。画像/音・グラフィック設定は論理結果に影響しない。

## 9. 完了判定

- プレイヤーがキーボード/マウスで都市を作成し、情報レイヤーで問題を発見し改善できる。
- 主要な建設可否・供給不足・通行制限は理由を表示する。
- 日本語/英語で全主要メニュー・施設・エラー・チュートリアルが表示可能。
- セーブ中断/破損データ/旧バージョンのエラーで現行都市を失わない。
- カメラ移動/情報レイヤー/写真モードを使っても交通や都市経済の結果が変化しない。
- 重要な情報を色だけで区別しない。キーの再割当と文字サイズ変更が機能する。
